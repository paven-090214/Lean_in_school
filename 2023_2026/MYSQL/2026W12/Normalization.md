## 1. 관계 데이터베이스의 정규화에 대한 설명이다. 괄호 안에 알맞은 것은?
### 어떤 릴레이션 R이 (①)이고, 릴레이션의 키가 아닌속성 모두가 R의 어떤 키에도 이행적 함수종속이 아닐 때R은 (②)에 속한다.
- 가. ① 1NF ② 2NF 
- 나. ① 1NF ② 3NF
- 다. ① 2NF ② 3NF 
- 라. ① 2NF ② 4NF
> 답: 다

## 2.어떤 릴레이션 R에서 X와 Y를 각각 R의 애트리뷰트 집합의 부분 집합이라고 할 경우, 애트리뷰트 X의 값 각각에 대하여 시간에 관계없이 항상 애트리뷰트 Y의 값이 오직 하나만 연관되어 있을때 Y는 X에 함수 종속이라 한다. 다음 표기 방법 중 이러한 성질을 잘 표현한 것은?
- 가. X → Y 		
- 나. Y → X
- 다. X ⊂ Y 		
- 라. Y ⊂ X
> 답: 가
## 3. 정규화하는 프로젝션 과정 중 부분함수 종속제거는 어느 단계에 속하는가?
- 가. 비정규 릴레이션 → 1NF      
- 나. 1NF → 2NF
- 다. 2NF → 3NF                  
- 라. 3NF → BCNF
> 답: 나
## 4. 다음의 조건을 모두 만족하는 정규형은?

### 모든 도메인은 원자 값이고 기본 키가 아닌 모든 속성들이 기본 키에 대해 완전 함수 종속적 이며, 이행적 함수 종속 관계는 제거되었다.

- 가. 제 1정규형		
- 나. 제 2정규형
- 다. 제 3정규형         
- 라. 제 1정규형과 제2정규형
> 답: 다

# [노트필기]

[요약] 정규화 과정
1. 제1정규형(1NF) : 비정규형 -> 1차정규형(1NF)
모든 속성은 원자값을 가지도록 하고, 반복그룹을 제거한다. 1차정규형 테이블이라고 한다.

2. 제2정규형(2NF) : 1차정규형 ->  2차정규형(2NF)
복합키의 일부분에 의해 종속되는 필드들이 존재할 경우 이를 제거 : (부분함수종속 제거)

3. 제3정규형(3NF) : 2차정규형 -> 3차정규형(3NF)
키가 아닌 일반 필드에 종속적인 필드가 존재할 경우 이를 제거 : (이행적함수종속 제거)
-------------------------------------
# 정규형
    비정규형   ->       1NF    ->    2NF    ->    3NF              ->              BCNF
                 원자값        완전함수종속    이행함수종속    결정자가 후보키
-------------------------------------
  1) 제 1 정규형(1NF) : 원자값(atomic value), 반복그룹 제거
  2) 제 2 정규형(2NF) : 부분함수종속 제거(완전함수종속)
          부분함수종속(partial function dependency)
          완전함수종속(full function dependency)

기본키에 완전함수종속이어야         

  3) 제 3 정규형(3NF) : 이행함수종속 제거
          이행함수종속(transitive function dependency)

키가 아닌 것에 종속되지 않아야
